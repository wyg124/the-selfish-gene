# The selfish gene

在线访问：[The Selfish Gene](https://wyg124.github.io/the-selfish-gene/) · [公开源码](https://github.com/wyg124/the-selfish-gene)

React + Vite 科普网站。根据用户提供的《自私的基因：40周年增订版》EPUB，保留全书目录、全文、插图、尾注与附录，并提供独立导读和互动。

## 运行

```sh
pnpm install
pnpm dev
```

构建：`pnpm build`。也可使用 npm install / npm run dev。

## 素材替换

- `public/gene-loop.mp4`：作品播放器中的原创程序生成6秒影片；新首屏由 Three.js 实时绘制。
- `public/gene-poster.jpg`：原视频占位图。
- `src/main.jsx`：页面结构、作品说明、电话与邮箱内容。
- `src/style.css`：1700px 首屏版心、响应式与视觉样式。

当前海报是 CSS 原创排版概念；后续可替换为真实海报图片。电话与邮箱已按用户提供的信息填入，并提供拨号与邮件链接。页面无后端和外部数据上传。

## 完整阅读版

- 按 EPUB 目录保留 25 个阅读单元：6 篇开篇材料、15 章正文、尾注与 3 项其他附录。
- 原文 360,694 个非空白字符；87 处原书图片引用，66 个独立图片文件。原书全文与导读分开。
- 15 章原创导读、179 条通俗术语解释，覆盖原书术语表全部 33 项；30 道自测。
- 原文术语注释、跨章节尾注导航、全书文本搜索、图片放大、字号控制。
- 本机阅读标记、章节笔记及 Markdown 导出；没有账号或服务端记录。
- 章节内含重组、鹰鸽预期收益、重复囚徒困境、延伸表型因果链、六类制约互动；原有亲缘选择实验保留。

`public/book/` 是章节分文件数据；点击章节按需加载，扫描图片懒加载，全书检索索引仅在搜索时载入。

内容检查：`node scripts/verify_content.mjs`。
重新导入同目录资料：`python3 scripts/import_book.py`。校验以目录顺序、原文字符、图片和注释跳转为基础。原文保留历史语境，导读也明确区分模型、比喻、推测、观察和作者在尾注中的更正。

## 章节按需阅读

卡片目录下方不再默认展开章节、文字目录、阅读进度或阅读正文。点击卡片后，打开阅读弹层，保留导读、完整原文、自测、术语、尾注导航和笔记；关闭后回到卡片目录。章节深链接仍可直接打开对应阅读弹层。

阅读弹层支持 Escape、固定关闭按钮、键盘焦点循环和独立滚动；术语、图片和搜索弹窗可以在阅读层上继续打开。

## 暖色学术玻璃主题与实验注释

`src/atmosphere.css` 统一网站的暖白半透明材质、连续背景底光、柔和描边和板块间距。各板块共用同一背景，减少独立实色背景造成的硬切换；移动端保留较轻的模糊效果。

亲缘选择实验新增收益 B 与成本 C 的旁注，解释各自对应的预期繁殖成功变化、给出例子，并实时显示当前 r × B − C。滑块与旁注通过 aria-describedby 关联。桌面采用三栏，小屏幕自动改为堆叠布局。

开场循环会在目录画面停留后，通过淡出与淡入平滑衔接到下一轮 DNA，无需手动重播。

## GitHub Pages 发布

仓库默认分支 `main`。`.github/workflows/deploy.yml` 会在推送后安装锁定依赖、校验全部阅读数据、构建并发布 `dist/`。首次发布需在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。

Vite 使用相对 base，图片、正文数据、视频和字体均兼容 GitHub Pages 仓库子目录。所有阅读笔记与进度仅保存在访问者本机浏览器，公开部署不上传这些记录。
